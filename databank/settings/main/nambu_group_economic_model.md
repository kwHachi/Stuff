# 南武集团特色计划经济模式

**南武集团特色计划经济模式**是[希节路线](kisetsu_line.md)的核心内容，也是[联合主义南武共和国](rengoist_republic_of_nambu.md)现行的根本经济制度。

该模式的标志性特征，是在[户岸希节](../people/tokishi_kisetsu.md)同志领导下，于2021年3月经济改革中，对建国初期仍广泛存在的私营生产劳动进行了全面、彻底的接管与收编。这一举措彻底根除了私有制的残余，将[联合所有制](comprehensive_leadership.md)从理论构想转变为现实，标志着共和国向纯粹的社会主义经济形态迈出了决定性的一步。

在此模式下，全国所有经济活动均由[南武集团](nambu_commonwealth.md)统一组织，并严格遵循[南武最高人民委员会](supreme_peoples_committee.md)制定的生产与分配计划，以确保生产力的发展完全服务于全体人民的共同利益。
