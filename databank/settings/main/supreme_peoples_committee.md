# 南武最高人民委员会

**南武最高人民委员会**（Supreme People's Committee of Nambu），是[南武联合党](nambu_rengoist_party.md)和[南武集团](nambu_commonwealth.md)的最高领导机构，也是[联合主义南武共和国](rengoist_republic_of_nambu.md)的最高决策核心。

## 基本情报

| 項目        | 内容                                        |
|:----------|:------------------------------------------|
| **性质**    | 党和集团的最高领导机构                               |
| **地位**    | 国家的最高决策核心                                 |
| **领导职位**  | 总书记                                       |
| **任期**    | 16年（对应两届[全南武进步者大会](nambu_congress.md)）    |
| **现任总书记** | [川伊八海](../people/kawai_hachimi.md)（第五、六届） |
| **核心制度**  | [全面领导制](comprehensive_leadership.md)      |

## 性质与职能

最高人民委员会是[全面领导制](comprehensive_leadership.md)的最高体现，由党的数位核心领导人组成，负责对党、国家、[南武集团](nambu_commonwealth.md)及[南武人民防卫军](peoples_defense_army.md)等所有机构实施统一和绝对的领导。

其核心职能包括：
- 制定国家在政治、经济、军事等所有领域的根本战略和方针。
- 领导和管理[南武集团](nambu_commonwealth.md)，审批国家级经济计划。
- 决定[联合主义](rengoism.md)的理论发展方向，领导意识形态工作。
- 指导并监督[南武中央人民政府](central_government.md)和[全南武进步者大会](nambu_congress.md)的工作。
- 通过党的军事机构，对[南武人民防卫军](peoples_defense_army.md)实施最高军事领导。

## 运作与换届

委员会每年定期召开全体会议，讨论和决定国家的重大问题。

委员会每十六年换届一次，与其领导人（总书记）的任期同步，该周期对应两届[“八年会”](nambu_congress.md)。

## 历代委员会与总书记

最高人民委员会的每一代领导集体都在[联合主义](rengoism.md)的理论基础上不断发展，形成了清晰的继承脉络。
